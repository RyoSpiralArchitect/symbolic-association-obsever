観察のための道具

hidden / attention は生成後に全文を再入力した forward pass の記録です。リアルタイムの思考や、象徴的意味の証明ではありません。hidden index 0 は通常 embedding 出力ですが、モデル仕様を確認してください。attention は保存順の slot と全文中の位置で表示します。元の層番号や token 列が保存されていない場合は復元できません。
